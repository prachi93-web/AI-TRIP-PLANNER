# 🌍 AI Trip Planner

An AI-powered travel planner built using the MERN stack and Gemini AI. Generate personalized travel itineraries based on your destination, budget, travel dates, interests, and preferred language. Users can also save trips and upload their travel memories.

## 🚀 Features

- 🔐 User Authentication (JWT)
- 🤖 AI Trip Generation using Gemini API
- 📅 Personalized Day-wise Itinerary
- 🌍 Destination Search
- 📌 Sample Trips
- 📸 Upload & Delete Trip Memories
- ☁️ Cloudinary Image Storage
- 📱 Fully Responsive UI

## 🛠️ Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT
- **AI:** Gemini API
- **Image Storage:** Cloudinary

## ⚙️ Installation

### Backend

```bash
cd server
npm install
npm start
```

### Frontend

```bash
cd client
npm install
npm run dev
```
